# docs/source/getting_started

The four pages `index.rst` includes to form the docs landing page.

## Files

- `overview.rst`: one-paragraph description of what Pauli propagation does,
  plus a diagram (`_static/ppdoc1.svg`).
- `usage.rst`: step-by-step walkthrough (imports, defining an ansatz,
  constructing a `Propagator`, `.propagate()`, evaluating, inspecting the
  symbolic expression).
- `installation.rst`: install steps, including building the Rust extension
  `pprop_rs` with maturin.
- `citation.rst`: BibTeX entries for citing this software/the paper.
